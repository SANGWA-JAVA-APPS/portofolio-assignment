# SANGWA Emmanuel Portfolio

A responsive personal portfolio presenting Eng. SANGWA Emmanuel's software engineering experience, services, selected projects, technology stack, and professional contact links.

## Features

- Responsive single-page layout with section navigation
- Professional profile and expandable About section
- Services covering business platforms, workflow automation, connected applications, and low-code solutions
- Selected project showcase for Gigaflex, port management, and inventory systems
- Technology stack overview
- LinkedIn and GitHub contact links

## How to Run This Project

### Prerequisites

- A modern web browser
- Git (optional, for cloning the repository)

### Installation

1. Clone the repository with `git clone https://github.com/SANGWA-JAVA-APPS/portofolio-assignment.git`.
2. Open the project directory.
3. Open `index.html` in a web browser. No package installation or build process is required.
